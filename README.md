# 📊 KRX 밸류에이션 대시보드

한국 주식시장(코스피/코스닥) 밸류에이션 지표를 매일 자동으로 수집해서 보여주는 웹 대시보드입니다.

## 주요 기능

- 코스피 / 코스닥 PER · PBR · 배당수익률
- 버핏 지수 (시가총액 ÷ GDP)
- 섹터별 밸류에이션 비교
- 개별 종목 스크리너 (PER/PBR 필터)
- 히스토리 추이 차트 (2년치)
- 매일 장 마감 후 자동 업데이트

---

## ⚡ 설치 방법 (5단계)

### 1단계 - 저장소 Fork 또는 생성
GitHub에서 이 저장소를 Fork하거나, 새 저장소를 만들고 파일을 업로드하세요.

### 2단계 - 파일 구조 확인
```
📁 저장소 루트
├── fetch_data.py              ← 데이터 수집 스크립트
├── README.md
├── .github/
│   └── workflows/
│       └── update.yml         ← 자동화 설정
└── docs/
    ├── index.html             ← 웹사이트
    ├── data.json              ← 오늘 데이터 (자동 생성)
    └── history.json           ← 히스토리 (자동 생성)
```

### 3단계 - GitHub Pages 활성화
1. 저장소 → **Settings** 탭
2. 왼쪽 메뉴 → **Pages**
3. Source: **Deploy from a branch**
4. Branch: **main** / Folder: **/docs**
5. **Save** 클릭

→ 약 1~2분 후 `https://[내GitHub아이디].github.io/[저장소이름]` 으로 접속 가능!

### 4단계 - 첫 데이터 수집 (수동 실행)
1. 저장소 → **Actions** 탭
2. 왼쪽: **📊 매일 KRX 데이터 업데이트** 클릭
3. **Run workflow** 버튼 클릭
4. 약 30초~1분 후 완료

### 5단계 - 완료! 🎉
웹사이트 주소로 접속하면 대시보드가 보입니다.

---

## 🔄 자동 업데이트

GitHub Actions가 **평일 오후 6시 30분(한국시간)** 마다 자동으로 실행됩니다.
별도 설정 없이 자동으로 매일 업데이트됩니다.
